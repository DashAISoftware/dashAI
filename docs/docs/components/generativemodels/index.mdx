# GenerativeModels

All registered `GenerativeModel` components in DashAI.

| Name | Description |
|------|-------------|
| [GenerativeModel](./GenerativeModel) | Abstract base class for all generative models. |
| [QwenModel](./QwenModel) | Qwen model for text generation using llama.cpp library. |
| [StableDiffusionV2Model](./StableDiffusionV2Model) | Stable Diffusion 2.x models for text-to-image generation. |
| [StableDiffusionV3Model](./StableDiffusionV3Model) | Stable Diffusion 3.x models for text-to-image generation. |
| [StableDiffusionXLV1ControlNet](./StableDiffusionXLV1ControlNet) | ControlNet with depth preprocessing and Stable Diffusion XL pipeline. |
