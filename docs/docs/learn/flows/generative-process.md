# Flow: Generative Process

<!-- TODO: Complete this flow with step-by-step screenshots and instructions -->

This flow walks through a complete generative workflow — from selecting a generative model to running a generation session and retrieving results.

## Prerequisites

- DashAI installed and running
- A generative model available (e.g., `QwenModel` for text, `StableDiffusionV2Model` for images)

## Steps

### 1. Navigate to Generative Sessions

From the main interface, open the **Generative** section.

### 2. Create a Session

Select a generative model and configure its parameters (e.g., `max_tokens`, `temperature`).

### 3. Run the Generation

Submit a prompt or input. The job is queued and processed in the background.

### 4. View Results

Once the job completes, inspect the generated output directly in the interface.
