# Cargar un Conjunto de Datos

Este tutorial te guiará a través del proceso de cargar un conjunto de datos en DashAI.

## Formatos Compatibles

DashAI admite varios formatos de conjuntos de datos:

* Archivos CSV (.csv)
* Archivos Excel (.xlsx, .xls)
* Archivos JSON (.json)
* Conjuntos de datos de imágenes (como archivos .zip)

Haz clic en el cargador de datos correspondiente al formato de tu conjunto de datos; en este caso, CSV, y luego haz clic en siguiente.

### 3. Seleccionar tu Archivo

  <code>step3.jpeg</code>

Haz clic en "Subir un Archivo" y selecciona el archivo de tu conjunto de datos desde tu computador.

### 4. Configurar los Parámetros

<div style={{background:'#f1f5f9',border:'2px dashed #cbd5e0',borderRadius:'8px',padding:'48px 24px',textAlign:'center',color:'#94a3b8',margin:'16px 0',fontSize:'14px'}}>
  📷 <strong>Screenshot placeholder</strong><br/>
  <code>step4.jpeg</code>
</div>

Establece los parámetros adecuados para tu conjunto de datos:

* Para archivos CSV:
    - Nombre
    - Delimitador (coma, punto y coma, etc.)

* Para archivos JSON:
    - Nombre
    - Clave de datos (clave donde se encuentran los datos)

* Para archivos Excel:
    - Nombre de la hoja
    - Encabezado (el número de fila donde se encuentran los nombres de columna)
    - Usecols (columnas a cargar)

1. Haz clic en el botón "Guardar"
2. Espera a que la carga se complete
3. Revisa el resumen para asegurarte de que la carga fue correcta
4. Verifica tu conjunto de datos en la lista de datasets

## Consejos y Solución de Problemas

* Asegúrate de que tu archivo esté en un formato compatible
* Verifica los límites de tamaño de archivo (3 GB para el conjunto de datos)
* Verifica la integridad de los datos antes de cargarlos
* Asegúrate de seleccionar el cargador de datos correcto para el formato de tu conjunto de datos
* Revisa el resumen del conjunto de datos para detectar errores
