# Estructura de un Plugin

## ¿De qué Está Compuesto un Plugin?

Un plugin está compuesto de 4 partes:

1. **src**: Esta carpeta contiene la carpeta con el **nombre del plugin o paquete**. Es importante que esto se cumpla.

   La carpeta con el nombre del plugin o paquete debe contener todos los archivos **Python** y **JSON** necesarios para extender el software.

2. **pyproject.toml**: Archivo de configuración. Este es responsable de determinar cómo se crea el paquete y qué metadatos contiene.

3. **readme.md**: Contiene la descripción larga del paquete o plugin.

4. **LICENSE**: Determina el tipo de licencia que tendrá el paquete.

La estructura de carpetas debe ser la siguiente:

```text
plugin_name
│   LICENSE
│   pyproject.toml
│   readme.md
└───src
    └───plugin_name
        │  example_model.py
        │  ExampleModel.json
```

## Partes Requeridas

Para que el software integre el plugin al instalarse, es necesario cumplir con los siguientes requisitos:

1. **pyproject.toml** DEBE contener un **entrypoint** para cada clase Python que desees agregar al software.

   ```toml
   [project.entry-points.'dashai.plugins']
   ExampleClass = 'plugin_name.example_class:ExampleClass'
   ```

2. **pyproject.toml** DEBE contener una sección **keywords**, donde se especificarán las etiquetas que se mostrarán al presentar el paquete o plugin en la interfaz de plugins de DashAI.

   Las únicas etiquetas posibles son:

   ```python
   "DashAI", "Package", "Task", "Model", "Dataloaders", "Converter", "Explainer"
   ```

   Una posible sección de keywords sería la siguiente:

   ```toml
   [project]
   keywords = [
       "DashAI",
       "Package",
       "Task",
       "Model",
       "Dataloader"
   ]
   ```
