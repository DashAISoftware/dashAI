# ¿Cómo Subir mi Plugin o Paquete a PyPI?

El primer paso es asegurarse de tener la estructura detallada en el siguiente archivo:

[Estructura de un Plugin](./structure)

Luego, antes de subir el plugin a PyPI, es necesario asegurarse de que funcione. Algunas recomendaciones para probarlo y los pasos a seguir para crear un plugin están disponibles en la siguiente página:

[Desarrollar un Plugin](./develop)

Finalmente, asegurándose de que los documentos anteriores han sido revisados, puedes crear el paquete en PyPI para subir el plugin.

## Tutorial para Subir un Plugin o Paquete a PyPI

**IMPORTANTE:** El siguiente tutorial usa twine para subir el paquete a PyPI. Sin embargo, existen muchas otras formas de hacerlo y eres libre de usar cualquiera.

1. Empaqueta los archivos. Para ello, ejecuta los siguientes comandos:

   ```bash
   python -m pip install --upgrade build
   python -m build
   ```

   Se crearán los siguientes archivos:

   ```text
   +---dist
         |  plugin-name-0.0.1--none-any.whl
         |  plugin-name-0.0.1.tar.gz
   ```

2. Solicita un token a PyPI. Esto se muestra en la siguiente página, en la sección "**How do I use API tokens to authenticate with PyPI?**"

   [Ayuda](https://test.pypi.org/help/#apitoken)

   Al usar Twine, esto es necesario por las medidas de seguridad de PyPI.

3. Sube el paquete a PyPI de prueba. Para ello, ejecuta los siguientes comandos:

   **IMPORTANTE:** PyPI tiene una versión de prueba para subir plugins y verificar que funcionen correctamente al descargarse. Para esto, reemplaza **"pypi"** por **"testpypi"** en el siguiente fragmento.

   ```bash
   python -m pip install --upgrade twine
   python -m twine upload --repository pypi dist/*
   ```

   Si el token está correctamente configurado, no debería haber ningún problema.

Con esto, el plugin habrá sido subido.
